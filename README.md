### given

<details>
<summary>释义、完整读法与听读实例</summary>

<a name="given-details"></a>

**释义**

在条件概率中，`P(A|B)` 表示“已知 B 发生时，A 发生的概率”。这里的竖线读作 **given**，相当于“给定”或“在已知……的条件下”。

**其他完整读法**

- **the conditional probability of A given B**：明确说明这是条件概率。
- **the probability of event A happening, given that B is true**：展开解释表达的含义。

### nabla / del

<details>
<summary>释义、完整读法与听读实例</summary>

<a name="nabla-details"></a>

**释义**

`∇` 是向量微分算子的符号，称为 **nabla** 或 **del**。与标量场或向量场结合，可以构成梯度、散度和旋度等运算。 [💡](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/a5910abd3b1b31bdb0c26ff1e0185ef2_MIT18_02SC_MNotes_v15.1.pdf)

**其他完整读法**

- **the nabla operator**：使用 nabla 这个名称。
- **the del operator**：使用 del 这个名称。

### gradient（梯度）

<details>
<summary>释义、完整读法与听读实例</summary>

<a name="gradient-details"></a>

**释义**

`∇f` 表示标量场 f 的梯度，结果是向量。在梯度非零的点，它指向 f 增长最快的方向，其大小表示该方向上的变化率。 [💡](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/a5910abd3b1b31bdb0c26ff1e0185ef2_MIT18_02SC_MNotes_v15.1.pdf)

**其他完整读法**

- **grad f**：梯度的简短读法。
- **the gradient of the scalar field f**：明确指出 f 是标量场。

### divergence（散度）

<details>
<summary>释义、完整读法与听读实例</summary>

<a name="divergence-details"></a>

**释义**

`∇·F` 表示向量场 F 的散度，结果是标量。点号在逐符号读法中读作 **dot**，因此可读 **del dot F**。 [💡](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/a5910abd3b1b31bdb0c26ff1e0185ef2_MIT18_02SC_MNotes_v15.1.pdf)

**其他完整读法**

- **del dot F**：逐符号读法，见 [MIT 课堂文字稿](https://ocw.mit.edu/courses/18-02-multivariable-calculus-fall-2007/b7d644f796f56b59a1e0d81f484b7869_wu8kXZSAp20.pdf)。
- **the divergence of the vector field F**：明确指出 F 是向量场。

<summary>释义、完整读法与听读实例</summary>

### Laplacian（拉普拉斯算子）

<details>
<summary>释义、完整读法与听读实例</summary>

<a name="laplacian-details"></a>

**释义**

`∇²f` 表示对标量场 f 施加拉普拉斯算子。在直角坐标系中，它等于 f 对各空间坐标的二阶偏导数之和，也等于梯度的散度。 [💡](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/a5910abd3b1b31bdb0c26ff1e0185ef2_MIT18_02SC_MNotes_v15.1.pdf)

**其他完整读法**

- **the Laplacian operator applied to f**：强调算子作用在 f 上。
- **the divergence of the gradient of f**：展开说明运算关系。
